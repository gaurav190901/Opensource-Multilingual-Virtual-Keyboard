Multilingual Virtual Keyboard

A free on-screen keyboard for English, Hindi, Marathi, Telugu, Bengali and Tamil. Click a field below to try it. Pick the language in the keyboard's header.

Use it in your project

<script src="https://cdn.jsdelivr.net/gh/gaurav190901/Opensource-Multilingual-Virtual-Keyboard@v1.0.0/dist/multilingual-keyboard.min.js"></script>
<script>
  MultilingualKeyboard.attach("input, textarea", { language: "hi" });
</script>

Full docs and options: GitHub repository
